# PaLoNex HQ

The public company platform for Palonex Solutions Private Limited. The initial foundation introduces the company, the ecosystem and seven AI product concepts.

Use Node 24 and npm. Install dependencies with `npm ci`, then run `npm run dev` and open http://localhost:3000.

See [project status](PROJECT_STATUS.md), [architecture](PROJECT_ARCHITECTURE.md), [development roadmap](DEVELOPMENT_ROADMAP.md), and [testing](TESTING_GUIDE.md).
