# Deployment guide

For a future Vercel deployment, import the connected GitHub repository, select the Next.js framework preset and Node 24, and leave the project root at the repository root. Run the checks in [Testing](TESTING_GUIDE.md) before promoting a preview.

The public foundation has no required environment variables. Configure enquiry storage securely when that feature is implemented. Verify canonical URLs, sitemap, indexing behavior and contact handling before connecting the official domain. Obtain founder authorization before changing production deployment or DNS.

Configure and verify the database, enquiry signing, email scheduler and retention before enabling business enquiries for production visitors. See [Backend setup](BACKEND_SETUP.md).
