# Design system

Matte black and metallic gold are the official PaLoNex colors. The CSS variables in `app/globals.css` define all shared color roles and their interaction states.

| Role | Value |
| --- | --- |
| Primary background | `#090909` |
| Secondary background | `#141414` |
| Cards | `#1B1B1B` |
| Metallic gold | `#D4AF37` |
| Champagne gold | `#F0D78C` |
| Deep gold | `#9C7620` |
| Primary text | `#F5F3ED` |
| Secondary text | `#AAA69B` |
| Borders | `#393328` |

Use metallic gold for accents and primary actions, champagne for focus and emphasis, and deep gold for decorative borders. Use the shared shell, card radius and system sans-serif typography. The header and footer use the same orbit symbol and PaLoNex wordmark in gold. A monochrome application can use the same mark and wordmark in the primary text color.

The product portfolio pairs the shared palette with a dedicated icon and geometric motif for each concept. The primary layout adjusts at 920, 760 and 450 CSS pixels. Preserve visible focus, semantic headings and motion preferences when adding components.
