# Design system

The foundation pairs deep navy surfaces with periwinkle accents, high-contrast type and a blue-violet fiber-optic hero. Use the CSS custom properties in `app/globals.css` for colors, card borders, radius and shadow. The typography uses a system sans-serif stack with an Inter preference.

Use the shared shell for page alignment, primary buttons for the main action and text links for contextual navigation. Use the same border and radius on cards and label planned products explicitly.

The primary layout adjusts at 920, 760 and 450 CSS pixels. Preserve visible focus, semantic headings and motion preferences when adding components.
